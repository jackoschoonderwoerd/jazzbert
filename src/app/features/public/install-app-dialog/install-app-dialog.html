Install Jazzbert

Want to receive a reminder 24 hours before each jazz concert?

First, add Jazzbert to your Home Screen. It's free and only takes a moment.

How to install Jazzbert

  1. Open Jazzbert in Safari on your iPhone or iPad.
  2. Tap the Share button (the square with an upward arrow).
  3. Scroll down and select Add to Home Screen.
  4. Tap Add to confirm.
  5. Open Jazzbert from its new Home Screen icon.

Enable notifications

Once you've opened the installed app, return to the About page and tap Enable notifications.

That's it! You'll receive a reminder 24 hours before each concert.
